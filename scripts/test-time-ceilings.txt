# Time ceiling per test binary, per judge host. scripts/test-times.sh reads it
# as the last step of merge-gate.sh, over the gate's own log up to the line
# `=== end of timed steps ===`: every `finished in` printed by the cargo test calls
# of run-all-tests.sh and of the --features docs step, summed per binary.
#
# A line: <os> <binary> <floor_s> <ceiling_s> <owner> <expires> <reason>
#   os         windows (Git Bash) or linux. A host is judged by its own lines only.
#   binary     <name> for rust/tests/<name>.rs (which has to exist), lib:<crate>
#              and bin:<crate> for unittests, doc:<crate> for doc-tests.
#   floor_s    whole seconds, at least 1. A run under it is red: the line no
#              longer describes the binary, lower it.
#   ceiling_s  whole seconds, above the default of 10. A run over it is red.
#   owner      one word.   expires  YYYY-MM-DD; the day after it, red.
#   reason     the rest of the line, never empty.
# A binary with no line has a ceiling of 10 s and no floor. A line whose binary
# this host's run did not run is red.
#
# How a line is set, from complete gate runs on that host, run alone:
#   ceiling = ceil(k x the slowest run), k = 1.3 with three runs or more, 1.5 with fewer
#   floor   = floor(0.5 x the fastest run)
#   a binary gets a line when k x its slowest run is above 10 s.
# Measured on 2026-10-14 from the 0.30 judge logs: windows, five runs from 111719e
# to b110ac2; linux, b110ac2 whole and fcebc6c up to the --features docs step.

# linux ran every binary ~2x slower. Run the gate alone (pesado) before moving a line.
