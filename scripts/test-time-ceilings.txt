# Time ceiling per test binary, per judge host. scripts/test-times.sh reads it
# as the last step of merge-gate.sh, over the gate's own log up to the line
# `=== end of timed steps ===`: every `finished in` printed by the cargo test calls
# of run-all-tests.sh, summed per binary. Since CI-K8 each binary runs once per judge:
# the --features docs pass is gone (docs is a default feature, the build without it is
# only linted), so a binary is no longer summed over two passes.
#
# A line: <os>[/gpu] <binary> <floor_s> <ceiling_s> <owner> <expires> <reason>
#   os         windows (Git Bash) or linux. A host is judged by its own lines only. `<os>/gpu` is the line of a binary that
#              ran on the card (CI-G1): lane R prints `=== models device: gpu for <binary> (...) ===` in the log before the
#              block of a binary it ran there, and test-times.sh judges THAT binary with its `<os>/gpu` line, or with the
#              default of 10 s and no floor when it has none, and never with the line `<os> <binary>` of the CPU. A binary with
#              no marker, or with a `cpu` or `unmanaged` one, is judged with `<os> <binary>`. Each device has the numbers
#              measured on it; a line of one device whose binary ran on the other is not red for having been left unused,
#              but it expires like any other.
#   binary     <name> for rust/tests/<name>.rs (which has to exist), lib:<crate>
#              and bin:<crate> for unittests, doc:<crate> for doc-tests.
#   floor_s    whole seconds, at least 1. A run under it is red: the line no
#              longer describes the binary, lower it.
#   ceiling_s  whole seconds, above the default of 10. A run over it is red.
#   owner      one word.   expires  YYYY-MM-DD; the day after it, red.
#   reason     the rest of the line, never empty.
# A binary with no line has a ceiling of 10 s and no floor. A line whose binary
# this host's run did not run is red.
#
# How a line is set, from complete gate runs on that host, run alone:
#   ceiling = ceil(k x the slowest run), k = 1.3 with three runs or more, 1.5 with fewer
#   floor   = floor(0.5 x the fastest run)
#   a binary gets a line when k x its slowest run is above 10 s.
# Measured on 2026-10-14 from the 0.30 judge logs: windows, five runs from 111719e
# to b110ac2; linux, b110ac2 whole and fcebc6c up to the --features docs step.
# A run on a machine loaded by another heavy job is not a measure: db28cd0-r2 on
# linux ran every binary ~2x slower. Run the gate alone (pesado) before moving a line.
# Rule that stands since 2026-11-10 (CI-E24): the ceiling is ceil(k x the slowest run that counts) and the floor is floor(0.5 x the fastest run that counts); a legitimate run slower than the ones a line was set on raises the ceiling (its numbers go in the reason) and the ceiling goes down when the runs allow it. A run in a shared turn of `pesado -p` counts from 2026-11-10; a run on a machine loaded by a job that is not a turn does not.
